# H.O.M.E. - Household Organization and Management Engine

**H.O.M.E.** (Household Organization and Management Engine) is a smart app designed to help individuals and families manage daily household tasks efficiently. It provides task management, automated distribution, and collaboration features to ensure that household duties are completed on time, improving productivity and reducing the burden of household chores.

## How to Run the Application

To run the application, you need to use Maven. You can follow one of these methods:

### Method 1: Using Maven in the IDE

1. Press on **Maven** in your IDE.
2. Navigate to **Plugins**.
3. Scroll down and find **JavaFX**, then click on it.
4. Press the second button: **JavaFX:run**.

### Method 2: Using the Terminal

1. Open the terminal.
2. Run the following command:
   ```bash
   mvn javafx:run
